## 💻 Open-Source Dependencies & Libraries

PhysTrackX relies on the open-source community. Key frameworks and models include:

* **NanoTrack (ONNX Backend):** Lightweight Siamese visual object tracking network \cite{chu2021nanotrack}.
* **Tesseract OCR:** Open-source optical character recognition engine \cite{smith2007overview}.
* **OpenCV:** Open-source computer vision library \cite{bradski2000opencv}.
